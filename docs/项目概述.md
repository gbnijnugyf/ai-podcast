# 数字人口播视频生成工具 — 项目概述

## 一、项目简介

**AI-Podcast** 是一个本地化脚本工具，可以将文本内容自动转化为带有 **3D 数字人主播** 的口播视频。项目采用模块化流水线架构，各环节可独立运行或跳过。

### 核心功能

| 功能 | 说明 |
|------|------|
| 🎙️ **语音合成** | 使用 Edge-TTS 将文本转为自然语音，支持多种中文音色 |
| 🧑 **数字人主播** | 加载 FBX 3D 模型，驱动口型同步 + 肢体动画，透明背景渲染 |
| 🎬 **幻灯片生成** | 调用 DeepSeek API 提取结构化大纲，Pillow 自动生成精美幻灯片 |
| 🔍 **话题搜索** | 通过 Bing 搜索最新资讯，自动生成口播文稿 |
| 🖼️ **背景图片** | 从 Pexels / Unsplash 自动搜索配图并下载 |
| 🎞️ **视频合成** | FFmpeg 合成最终视频：幻灯片背景 + 数字人叠加 + 字幕 + 音频 |

### 视频画面布局

```
┌─────────────────────────────────────────────┐
│                                             │
│           幻灯片内容                         │
│         （标题、要点、配图）                  │
│                                             │
│                                             │
│                          ┌────────────┐     │
│                          │            │     │
│                          │  数字人形象 │     │
│                          │ (口型+肢体) │     │
│                          └────────────┘     │
└─────────────────────────────────────────────┘
```

### 技术栈

| 组件 | 技术选型 | 说明 |
|------|----------|------|
| 编排语言 | Python 3.11 | 脚本编排、调用各组件 |
| 语音合成 | Edge-TTS | 微软免费 TTS，中文效果好 |
| 音素对齐 | pypinyin + 比例分配 | 演示级方案，可升级为 MFA |
| 口型驱动 | 中文音素 → Viseme 映射表 | 基于 ARKit 15 viseme 标准 |
| 3D 渲染 | Blender 4.x Python API | 模型加载、动画驱动、离线渲染 |
| 肢体动画 | Mixamo 预设动画（FBX） | idle、手势、指向等 |
| 幻灯片生成 | DeepSeek API + Pillow | LLM 提取大纲 + 渐变/图片背景 |
| 视频合成 | FFmpeg | 幻灯片 + 数字人叠加 + 音频合并 |

## 二、系统架构

### 整体数据流

```
输入文本 / 话题搜索
    │
    ├──→ 话题模式：Bing 搜索 → LLM 整理文稿
    │
    ▼
DeepSeek API 提取结构化大纲 → 生成幻灯片图片（Pillow）
    │
    ▼
Edge-TTS 语音合成（逐页合成 + 拼接）
    │
    ├──→ 每页音频 + word-level 时间戳
    │
    ▼
音素对齐（pypinyin → 按比例分配时长）
    │
    ▼
音素 → Viseme 映射（中文音素查表）
    │
    ▼
Blender 渲染数字人帧序列
    │
    ├── 加载 3D 模型（FBX）
    ├── 驱动口型动画 + 肢体动画（NLA 拼接）
    ├── 透明背景渲染
    │
    ▼
FFmpeg 最终合成
    ├── 幻灯片作为背景
    ├── 数字人叠加到右下角
    ├── 混入音频 + 字幕
    └──→ 最终视频（MP4）
```

### 两种工作模式

1. **文本模式（默认）**：输入讲解文本 → 自动生成幻灯片 → 合成视频
2. **话题模式**：指定话题 → Bing 搜索资讯 → LLM 生成口播文稿 → 合成视频

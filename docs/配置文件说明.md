# 配置文件说明

配置文件 `config.yaml` 位于项目根目录，采用 YAML 格式，包含所有模块的参数配置。

---

## 完整配置项

```yaml
# ============================================================
# Blender 3D 渲染引擎配置
# ============================================================
blender:
  path: "D:/ApplicationD/blender/blender.exe"    # Blender 可执行文件路径

# ============================================================
# FFmpeg 视频处理工具配置
# ============================================================
ffmpeg:
  path: "D:/ApplicationD/ffmpeg-8.0.1-essentials_build/bin/ffmpeg.exe"     # FFmpeg 路径
  ffprobe_path: "D:/ApplicationD/ffmpeg-8.0.1-essentials_build/bin/ffprobe.exe"  # FFprobe 路径

# ============================================================
# DeepSeek LLM API 配置（用于文稿生成和幻灯片大纲提取）
# ============================================================
deepseek:
  api_key: "sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"  # DeepSeek API Key
  base_url: "https://api.deepseek.com"       # API 地址
  model: "deepseek-chat"                     # 模型名称

# ============================================================
# Pexels 图片/视频搜索 API 配置
# ============================================================
pexels:
  api_key: "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"  # Pexels API Key
  cache_dir: "asset/images"                  # 媒资缓存目录

# ============================================================
# Pixabay 图片/视频搜索 API 配置
# ============================================================
pixabay:
  api_key: "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"  # Pixabay API Key（https://pixabay.com/api/docs/）

# ============================================================
# 话题背景媒资策略
# ============================================================
media:
  max_videos: 0                               # 全片最多使用视频背景的 block 数（0=全用静图）；可被 CLI --max-videos 覆盖
  per_page: 8                                 # 每个源每次检索返回条数

# ============================================================
# 幻灯片生成配置
# ============================================================
slides:
  bg_dir: "asset/templates/slide_bg"         # 静态模板背景图目录
  output_dir: "output/slides"                # 幻灯片输出目录
  width: 1920                                 # 幻灯片宽度（像素）
  height: 1080                                # 幻灯片高度（像素）
  font_path: "C:/Windows/Fonts/msyh.ttc"     # 中文字体路径
  font_index: 0                               # ttc 字体索引（0=常规，1=粗体）
  bg_mode: "gradient"                         # 背景模式：gradient(渐变) / static(固定模板)

# ============================================================
# TTS 语音合成配置
# ============================================================
tts:
  voice: "zh-CN-YunxiNeural"                 # 音色
  rate: "+15%"                                # 语速调节（-50% ~ +100%）
  output_dir: "output/audio"                  # 音频输出目录

# ============================================================
# 数字人渲染配置
# ============================================================
render:
  avatar_size: 320                            # 数字人画面尺寸（像素）
  fps: 30                                     # 渲染帧率
  output_dir: "output/avatar"                 # 帧序列输出目录

# ============================================================
# 视频合成配置
# ============================================================
video:
  output_dir: "output/video"                  # 视频输出目录
  format: "mp4"                               # 输出格式
  intro_video: "asset/templates/started/日报片头.mp4"  # 片头视频路径

# ============================================================
# 动画效果配置
# ============================================================
animation:
  # --- 页间转场 ---
  transition_type: "fadeblack"                # 转场类型
  transition_duration: 0.6                    # 转场时长（秒）

  # --- 页内元素入场动画 ---
  element_animation: true                     # 是否启用入场动画
  intro_duration: 0.8                         # 入场动画总时长（秒）
  title_effect: "fade_down"                   # 标题效果：fade_down / fade_in
  point_effect: "fade_left"                   # 要点效果：fade_left / fade_in
  image_effect: "scale_up"                    # 配图效果：scale_up / fade_in
```

## 配置项详解

### Blender 配置

- `path`：Blender 可执行文件的完整路径。如果 Blender 已加入系统 PATH，可直接写 `"blender"`。

### FFmpeg 配置

- `path`：FFmpeg 可执行文件路径
- `ffprobe_path`：FFprobe 可执行文件路径（用于获取音视频时长）

### DeepSeek 配置

- `api_key`：DeepSeek API 密钥，从 [DeepSeek 平台](https://platform.deepseek.com/) 获取
- `base_url`：API 端点地址，默认 `https://api.deepseek.com`
- `model`：模型名称，如 `deepseek-chat`、`deepseek-reasoner`

### Pexels 配置

- `api_key`：Pexels API 密钥，从 [Pexels 开发者平台](https://www.pexels.com/api/) 注册获取

### Pixabay

- `api_key`：Pixabay API 密钥，从 [Pixabay API](https://pixabay.com/api/docs/) 获取

### media

| 字段 | 说明 | 默认 |
|------|------|------|
| `max_videos` | 话题模式全片最多视频背景段数；`0` 表示全部静图 | `0` |
| `per_page` | 各源每次搜索返回候选数 | `8` |

CLI `--max-videos` 优先于配置文件。
- `cache_dir`：下载图片的缓存目录，MD5 文件名避免重复下载

### Slides 配置

| 参数 | 说明 | 推荐值 |
|------|------|--------|
| `bg_mode` | `"gradient"` 使用程序化渐变+蒙版；`"static"` 使用固定背景模板 | `"gradient"` |
| `font_path` | 中文字体路径，Windows 默认 `msyh.ttc`（微软雅黑）；Linux 可用 Noto Sans CJK | 视系统而定 |
| `font_index` | TTC 字体集索引，0=常规，1=粗体 | 0 |

### TTS 配置

**可用音色：**

| 音色值 | 说明 |
|--------|------|
| `zh-CN-XiaoxiaoNeural` | 女声（温柔自然） |
| `zh-CN-YunxiNeural` | 男声（阳光自然） |
| `zh-CN-YunjianNeural` | 男声（播音腔） |
| `zh-CN-XiaoyiNeural` | 女声（活泼可爱） |
| `zh-CN-YunyangNeural` | 男声（沉稳） |

**语速调节：**
- `"+0%"` — 正常语速
- `"+15%"` — 稍快（推荐口播用）
- `"+30%"` — 快速
- `"-10%"` — 稍慢

### Animation 配置

**转场类型（`transition_type`）：**

| 类型 | 效果 |
|------|------|
| `fade` | 淡入淡出 |
| `fadeblack` | 通过黑色淡入淡出 |
| `dissolve` | 溶解过渡 |
| `wipeleft` | 向左擦除 |
| `slideright` | 向右滑动 |
| `circlecrop` | 圆形裁剪 |

**入场动画效果：**
- `title_effect`：`fade_down`（上滑+淡入） / `fade_in`（原地淡入）
- `point_effect`：`fade_left`（左滑+淡入） / `fade_in`（原地淡入）
- `image_effect`：`scale_up`（缩放出现） / `fade_in`（原地淡入）

# 使用指南

---

## 一、环境准备

### 1.1 安装依赖

```bash
pip install -r requirements.txt
```

核心依赖包括：
- `openai` — DeepSeek API 调用
- `edge-tts` — 语音合成
- `pypinyin` — 中文拼音转换
- `Pillow` — 图片处理
- `requests` — HTTP 请求
- `PyYAML` — 配置解析
- `numpy` — 数值计算

### 1.2 安装外部工具

| 工具 | 用途 | 下载地址 |
|------|------|----------|
| Blender 4.x | 3D 模型渲染 | https://www.blender.org/download/ |
| FFmpeg | 视频合成 | https://ffmpeg.org/download.html |

### 1.3 获取 API Key

| API | 用途 | 获取地址 |
|-----|------|----------|
| DeepSeek | 文稿生成 + 大纲提取 | https://platform.deepseek.com/ |
| Pexels（可选） | 背景图片/视频搜索 | https://www.pexels.com/api/ |
| Pixabay（可选） | 背景图片/视频搜索 | https://pixabay.com/api/docs/ |

### 1.4 配置

编辑 `config.yaml`，填入以下必要信息：

```yaml
deepseek:
  api_key: "你的DeepSeek API Key"    # 必填

blender:
  path: "你的Blender安装路径"          # 需要数字人时必填

ffmpeg:
  path: "你的FFmpeg安装路径"           # 必填
  ffprobe_path: "你的FFprobe安装路径"  # 必填
```

## 三、话题模式

### 3.1 指定话题

搜索指定主题的最新资讯并生成口播视频：

```bash
python main.py --script-json output/script_20260627_000204.json
```

或使用桥接脚本：

```bash
python generate_video_from_report.py --topic "AI大模型最新进展"
```

### 3.2 自动选取热门话题

```bash
python generate_video_from_report.py --topic
```

自动从今日热搜中选取 2-3 个热门话题。

### 3.3 节目形态（`--genre`）

话题 / 文稿模式可切换节目形态（默认 `daily_brief`，与历史行为一致）：

| 取值 | 片头标题 | 文案口吻 / 结尾 |
|------|----------|-----------------|
| `daily_brief` | `日期` + `热点资讯` | 时事快报、「两分钟」订阅话术 |
| `general` | 脚本 / 话题标题 | 通用讲解、中性结尾 |

```bash
# 通用形态：片头显示话题标题
python generate_video_from_report.py --topic "量子计算" --genre general

# 批量时全局指定（topics.txt 仍每行一个 topic）
python batch_generate.py --topics-file topics.txt --genre general

# 已有 script JSON 时也可指定
python main.py --script-json output/script_xxx.json --genre general
```

### 3.4 口播时长与片头

| 参数 | 含义 | 默认 |
|------|------|------|
| `--duration` | 口播目标时长（**分钟**），引导文案字数/章节结构 | `2` |
| `--intro` | `asset/templates/started/` 下的片头文件名（可省略 `.mp4`） | `config.yaml` 中的 `video.intro_video` |

开场白字数按所选片头视频的实际时长引导；合成时若开场口播仍长于片头，溢出部分并入第一张背景图（与原有逻辑一致）。

```bash
# 1 分钟 + 通用片头 + 通用形态
python generate_video_from_report.py --topic "量子计算" --genre general --duration 1 --intro 通用片头

# 批量透传
python batch_generate.py --topics-file topics.txt --genre general --duration 1 --intro 通用片头.mp4

# 仅换片头（已有 script JSON）
python main.py --script-json output/script_xxx.json --intro 通用片头
```

当前 `started/` 常见文件：`日报片头.mp4`、`通用片头.mp4`。

### 3.5 背景媒资（多源图/视频）

话题模式从 **Pexels + Pixabay** 检索横版图片；可选检索视频。按标题/标签与 keyword 规则打分选优，并跨块去重。

| 参数 | 含义 | 默认 |
|------|------|------|
| `--max-videos` | 全片最多使用视频背景的 block 数 | `0`（全部静图） |

视频名额分给「视频相对图片相关度优势」最高的若干块；其余块用静图。需在 `config.yaml` 配置 `pexels.api_key`，建议同时配置 `pixabay.api_key`。

```bash
# 最多 2 段背景为视频
python generate_video_from_report.py --topic "量子计算" --genre general --max-videos 2

python batch_generate.py --topics-file topics.txt --max-videos 2
```

### 3.6 使用已有背景图 / TTS 续跑

跳过图片下载，从 TTS 阶段继续：

```bash
python main.py --script-json output/script_20260627_000204.json --bg-dir output/slides/topic_bg
```

TTS 会写入 `output/audio/slide_XXX.mp3` 与 `tts_cache.json`。若上次在 TTS 或后续步骤中断，用同一文稿与音色/语速重跑时，已合成页会直接复用，只补缺失页。视频生成成功后会自动清理这些缓存，避免和下一次任务混用。

## 六、流水线分步说明

整个视频生成按以下步骤执行，每一步都可以单独调试：

### 第 1 步：生成幻灯片

- **自动模式**：DeepSeek 提取大纲 → Pillow 合成图片
- **手动模式**：`--slides-dir` 指定已有图片目录
- **输出**：`output/slides/slide_001.png` ...（PNG 序列）

### 第 2 步：TTS 语音合成

- 逐页合成语音
- 输出每页的独立音频文件（`output/audio/slide_001.mp3` ...）
- 收集 word-level 时间戳
- 最终拼接为完整音频（`output/audio/full.mp3`）

### 第 3 步（可选）：渲染数字人

- 调用 Blender 渲染透明背景的帧序列
- 输出到 `output/avatar/frame_0001.png` ...
- 使用 `--no-avatar` 跳过此步骤

### 第 4 步：生成字幕

- 根据 TTS 时间戳生成 SRT 字幕文件
- 输出到 `output/video/subtitles.srt`

### 第 5 步：视频合成

- FFmpeg 合成最终视频
- 幻灯片 + 数字人叠加 + 字幕 + 音频
- 输出到 `output/video/output.mp4`

## 八、常见问题

### Q: 没有 Blender 怎么办？
使用 `--no-avatar` 参数跳过数字人渲染，仅生成幻灯片 + 语音视频。

### Q: TTS 语音合成太慢？
可以尝试减少文本量，或使用更快的音色。Edge-TTS 为在线服务，速度受网络影响。

### Q: 如何更换数字人模型？
将 FBX 模型放在 `asset/` 目录下，使用 `--model` 参数指定路径：
```bash
python main.py --model asset/your_model.fbx
```

### Q: 如何添加更多动画？
将 Mixamo 动画 FBX 文件放入 `asset/animations/` 目录，程序会自动加载并随机拼接。

### Q: 背景图片搜索失败？
- 检查 `config.yaml` 中 Pexels API Key 是否正确
- 没有 API Key 时会自动降级为 Unsplash 或纯色背景
- 确保网络可以访问 Pexels API

### Q: DeepSeek API 调用失败？
- 检查 API Key 是否正确
- 检查账户余额
- 检查网络是否能访问 `api.deepseek.com`

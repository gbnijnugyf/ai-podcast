## 三、时序图 — 完整流水线

```mermaid
sequenceDiagram
    participant User
    participant Main as main.py
    participant SG as SlideGenerator
    participant TTS as TTSEngine
    participant Renderer as Renderer
    participant Composer as VideoComposer

    User->>Main: python main.py --text "..."

    rect rgb(200, 230, 255)
        Note over Main,SG: 第 1 步：生成幻灯片
        Main->>SG: generate(text, output_dir)
        SG->>DeepSeek: 提取结构化大纲
        DeepSeek-->>SG: 幻灯片数据 (slides)
        SG->>Pexels: 搜索配图
        Pexels-->>SG: 图片路径
        SG->>Pillow: 合成幻灯片图片
        SG-->>Main: slides_data, slide_paths, frame_dirs
    end

    rect rgb(200, 255, 230)
        Note over Main,TTS: 第 2 步：TTS 语音合成
        Main->>TTS: synthesize_slides(slides_data)
        TTS->>Edge-TTS: 逐页合成
        Edge-TTS-->>TTS: 音频 + 时间戳
        TTS-->>Main: audio_paths, all_timestamps
        Main->>Composer: concat_audio() → full.mp3
    end

    rect rgb(255, 230, 200)
        Note over Main,Renderer: 第 3 步：数字人渲染（可选）
        Main->>Renderer: render_animation(fbx, duration)
        Renderer->>Blender: blender --background --python blender_driver.py
        Blender-->>Renderer: 帧序列 (frame_*.png)
        Renderer-->>Main: avatar_dir
    end

    rect rgb(255, 200, 200)
        Note over Main,Composer: 第 4 步：字幕生成
        Main->>Main: generate_srt() → subtitles.srt
    end

    rect rgb(230, 200, 255)
        Note over Main,Composer: 第 5 步：视频合成
        Main->>Composer: compose(slides, avatar, audio, srt)
        Composer->>FFmpeg: 合成最终视频
        FFmpeg-->>Composer: output.mp4
        Composer-->>Main: output_path
    end

    Main-->>User: 完成！输出视频
```

## 四、话题模式数据流

```mermaid
sequenceDiagram
    participant User
    participant Main as main.py
    participant Gen as ScriptGenerator
    participant Searcher as TopicSearcher
    participant BG as BackgroundSearcher
    participant TTS as TTSEngine
    participant Composer as VideoComposer

    User->>Main: --script-json script.json

    Main->>Main: 加载 script.json
    Main->>Main: 解析 opening + blocks

    rect rgb(200, 230, 255)
        Note over Main,BG: 下载背景图
        Main->>BG: download_for_script(script_data)
        BG->>Pexels: 搜索每块背景
        Pexels-->>BG: 图片 URL
        BG-->>Main: bg_paths[]
    end

    rect rgb(200, 255, 230)
        Note over Main,TTS: TTS 合成（opening + all blocks）
        Main->>TTS: synthesize_slides(all_slides_data)
        TTS-->>Main: audio_paths, timestamps
        Main->>Composer: concat_audio() → full.mp3
    end

    rect rgb(230, 200, 255)
        Note over Main,Composer: 视频合成（含片头）
        Main->>Composer: compose_topic_video(bg_paths, durations, audio, intro_video)
        Composer->>FFmpeg: 片头视频 + 背景图切换 + 音频
        FFmpeg-->>Composer: 最终视频
    end
```

## 五、类结构图

### 核心类关系

```mermaid
classDiagram
    class ScriptGenerator {
        +generate(topic) dict
        -_parse_response(raw) dict
        -_append_ending(data)
    }

    class TopicSearcher {
        +search(topic, max_results) List
        +summarize(topic, results) str
        -_search_bing_news()
        -_search_bing_web()
    }

    class SlideGenerator {
        +generate(text, output_dir) tuple
        +render_slide(data, index, total) str
        +render_slide_frames(data, index, total, dir) list
        -_build_prompt() str
        -_generate_gradient_bg() Image
        -_search_bg_from_pexels() str
    }

    class BackgroundSearcher {
        +search_and_download(keyword) str
        +download_for_script(data, dir) list
        -_search_pexels(keyword) str
        -_search_unsplash(keyword) str
        -_resize_to_fullscreen(src, dst)
    }

    class TTSEngine {
        +synthesize_text(text, filename) tuple
        +synthesize_slides(slides_data) tuple
        +save_timestamps(ts, filename) str
        -_synthesize(text, path) list
    }

    class Renderer {
        +render_test_frame(fbx, output) str
        +render_animation(fbx, duration, anim, dir) str
    }

    class VideoComposer {
        +concat_audio(paths, output) str
        +get_audio_duration(path) float
        +compose(slides, durations, avatar, audio, output, srt) str
        +compose_topic_video(...) str
        -_make_slide_video()
        -_concat_with_xfade()
        -_compose_final()
    }

    ScriptGenerator --> TopicSearcher
    ScriptGenerator --> BackgroundSearcher
    SlideGenerator --> TopicSearcher
    SlideGenerator --> BackgroundSearcher
    VideoComposer --> TTSEngine
```

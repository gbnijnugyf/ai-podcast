# 模块详细说明

本文档对 `src/` 目录下的各模块逐一说明其功能、输入输出和核心逻辑。

---

## 1. `script_generator.py` — 口播文稿生成

### 功能

根据指定主题，搜索最新资讯 → 调用 DeepSeek LLM 生成结构化口播文稿（JSON）。

### 工作流程

1. 初始化 `TopicSearcher`，搜索指定主题的最新资讯（最多 12 条）
2. 将搜索结果拼接成提示词，调用 DeepSeek API
3. 解析 LLM 返回的 JSON，自动追加随机结束语
4. 返回结构化数据

### 输出格式

```json
{
  "title": "视频主题标题",
  "opening": "1-2句话点题，约20-30字",
  "chapters": [
    {
      "chapter_title": "章节标题",
      "blocks": [
        {
          "keyword": "english image search keyword",
          "narration": "2-3个分句的口播文本，约30-60字"
        }
      ]
    }
  ]
}
```

### 关键特性

- 支持 `genre`（`daily_brief` / `general`）：影响写作风格补充说明与结束语池
- 结束语按 genre 从预设池随机选用
- 每个 block 包含 `keyword`（图片搜索关键词）和 `narration`（口播文本）
- 输出 JSON 可含 `genre` 字段，供合成阶段读取

## 1b. `genre.py` — 节目形态

### 功能

定义话题口播的节目形态（片头标题规则、结束语、文案 tone）。

| Genre | 片头 | 说明 |
|-------|------|------|
| `daily_brief` | 日期 +「热点资讯」 | 默认，兼容历史行为 |
| `general` | 脚本 / 话题标题 | 通用讲解形态 |

主要 API：`resolve_genre()`、`format_intro_title()`。

## 2. `topic_searcher.py` — 主题搜索

### 功能

从 Bing 搜索指定主题的最新资讯，可选的自动话题选择。

### 核心方法

| 方法 | 说明 |
|------|------|
| `search(topic, max_results)` | 使用 Bing 新闻搜索，降级到网页搜索 |
| `summarize(topic, search_results)` | 调用 LLM 整理搜索结果为资讯简报 |
| `auto_select_topics(date)` | 从金融日报 + Bing 热搜中自动选取 2-3 个热门话题 |

### 搜索策略

1. 优先使用 Bing 新闻搜索（`cn.bing.com/news/search`）
2. 新闻搜索无结果时降级到网页搜索（`cn.bing.com/search`）
3. 解析 HTML 提取标题和摘要
4. 通过 LLM 做信息整理和话题筛选

### 配置

```yaml
search:
  timeout: 20   # 搜索超时秒数
```

## 3. `slide_generator.py` — 幻灯片自动生成

### 功能

输入讲解文本 → DeepSeek 提取结构化大纲 → Pillow 合成幻灯片图片。支持逐帧元素入场动画。

### 核心流程

```
讲解文本
    │
    ▼
DeepSeek API 提取结构化大纲
    ├── 自动分页（封面、内容页、章节分隔、结尾）
    ├── 每页标题、要点、配图关键词
    │
    ▼
Pillow 合成图片
    ├── 渐变背景 / Pexels 深色背景 / 静态模板
    ├── 半透明蒙版保障文字可读性
    ├── 标题、要点文字渲染
    ├── 配图搜索下载并嵌入
    │
    ▼
逐帧入场动画（可选）
    ├── 标题滑入淡入
    ├── 要点逐行滑入
    ├── 配图缩放出现
    └── 输出 PNG 帧序列
```

### 幻灯片类型

| 类型 | 说明 |
|------|------|
| `cover` | 封面页，显示标题 + 副标题 |
| `content` | 正文内容页，标题 + 要点列表 + 可选配图 |
| `section` | 章节分隔页，仅显示章节标题 |
| `ending` | 结尾页，"谢谢观看" |

### 风格变体

内置 4 种写作风格，每次随机选取：

1. **贴吧毒舌博主** — 阴阳怪气、反讽类比
2. **知乎大V知性主播** — 深度降维解释
3. **B站邻家UP主** — 轻松随意接地气
4. **微博热搜达人** — 脱口秀节奏包装信息

### 背景生成

- 优先从 Pexels 搜索深色背景图片
- 降级使用程序化渐变背景（10 套预设色板）
- 支持静态模板背景

## 4. `background_searcher.py` — 背景媒资搜索

### 功能

多源检索横版图片/视频（Pexels + Pixabay），按标题/标签与 keyword 规则打分，跨块去重后下载；支持 `max_videos` 限制视频背景段数。

### 核心方法

| 方法 | 说明 |
|------|------|
| `search_and_download(keyword)` | 单关键词下载一张最优图（兼容旧接口） |
| `download_for_script(script_data, output_dir, max_videos=0)` | 为每个 block 下载背景（jpg 或 mp4） |

### 搜索策略

1. 图片：Pexels + Pixabay；均失败时降级 Unsplash Source
2. 视频：仅当 `max_videos > 0` 时检索 Pexels/Pixabay 视频
3. 规则打分选优；视频名额按「相对图片的相关度优势」分配
4. 黑名单：候选 `title`/`tags` 含 `openai`、`chatgpt`、`chat gpt` 则剔除（见 `BLOCKED_MEDIA_TERMS`）
5. 跨块按 `media_id` 去重；失败则本地兜底图
6. 缓存键为 media_id 的 MD5

### 图片处理

- 静图：居中裁切后缩放到 1920x1080，JPEG quality=92
- 视频：原样缓存，合成阶段由 Composer 循环/裁切到段时长

## 5. `tts.py` — TTS 语音合成

### 功能

使用 Edge-TTS 将文本转换为语音，同时收集 word-level 时间戳。

### 核心方法

| 方法 | 说明 |
|------|------|
| `synthesize_text(text, filename)` | 合成一整段文本，返回 (audio_path, timestamps) |
| `synthesize_slides(slides_data)` | 按幻灯片分页逐页合成；命中缓存则复用已合成页 |
| `clear_cache()` | 删除 `slide_*.mp3` / `full.mp3` / `tts_cache.json` |

### 断点缓存

- 元数据：`output/audio/tts_cache.json`（指纹 = narrations + voice + rate，及每页 timestamps）
- 指纹一致且对应 `slide_XXX.mp3` 存在 → 跳过该页合成
- 指纹不一致 → 清空旧缓存后重新合成
- 视频合成成功后由 `main.py` 调用 `clear_cache()`，避免下次混用

### 时间戳

- 收集 `WordBoundary` 和 `SentenceBoundary` 事件
- 单位：毫秒
- 可用于字幕生成和音素对齐

### 配置

```yaml
tts:
  voice: "zh-CN-YunxiNeural"    # 音色
  rate: "+15%"                   # 语速调节
  output_dir: "output/audio"
```

### 可用音色

| 音色 | 说明 |
|------|------|
| zh-CN-XiaoxiaoNeural | 女声（温柔） |
| zh-CN-YunxiNeural | 男声（自然） |
| zh-CN-YunjianNeural | 男声（播音） |
| zh-CN-XiaoyiNeural | 女声（活泼） |

## 6. `aligner.py` — 音素对齐

### 功能

将中文文本转换为音素序列（声母 + 韵母），并基于音频时长按比例分配每个音素的时间。

### 核心接口

```python
align_text(text: str, duration_ms: float, start_ms: float = 0) -> list[dict]
```

### 输出示例

```json
[
  {"phoneme": "n", "start_ms": 0, "end_ms": 50, "char": "你"},
  {"phoneme": "i", "start_ms": 50, "end_ms": 120, "char": "你"}
]
```

### 实现方案

1. **音素提取**：使用 `pypinyin` 库的 `lazy_pinyin` 获取拼音
2. **声韵拆分**：按声母列表匹配拆分声母和韵母
3. **时长分配**：
   - 中文字权重 2.0，字母数字 1.5，标点 0.8，其他 0.3
   - 按比例分配总时长
   - 声母占 35%，韵母占 65%

> **注意**：当前为演示级方案，后续可升级为 Montreal Forced Aligner (MFA) 获得更精确对齐。

## 7. `viseme.py` — 音素 → Viseme 映射

### 功能

将中文拼音音素映射为标准 viseme（口型），用于驱动 3D 模型的口型动画。

### 核心接口

| 接口 | 说明 |
|------|------|
| `phoneme_to_viseme(phoneme)` | 单个音素映射 |
| `timeline_to_visemes(phoneme_timeline)` | 音素时间轴 → Viseme 时间轴 |
| `viseme_at_time(viseme_timeline, time_ms)` | 查询指定时间的 viseme 状态 |
| `save_viseme_map(output_path)` | 导出映射表为 JSON |

### Viseme 映射表

| Viseme | 口型描述 | 对应中文音素 |
|--------|----------|-------------|
| sil | 闭嘴/静默 | 停顿 |
| PP | 双唇闭合 | b, p, m |
| FF | 下唇咬上齿 | f |
| DD | 舌尖抵上齿龈 | d, t, n, l |
| kk | 舌根抬起 | g, k, h |
| CH | 嘴唇微圆前突 | zh, ch, sh, r |
| SS | 齿缝送气 | z, c, s, j, q, x |
| aa | 大开口 | a, ai, ao, an, ang |
| EE | 扁唇展开 | i, ei, ie, in, ing |
| II | 中开口 | e, en, eng |
| OO | 嘴唇圆形 | o, ou, ong, uo |
| UU | 小圆唇 | u, ü, ue, un |
| RR | 卷舌 | er |

每种 viseme 还带有 `jaw`（下颌张开程度，0~1）权重，用于骨骼驱动。

## 8. `blender_driver.py` — Blender 驱动脚本

### 功能

在 Blender Python 环境中执行，加载 FBX 模型、设置场景、渲染输出。

### 调用方式

```bash
blender --background --python blender_driver.py -- <fbx_path> <output_path> <width> <height> [mode] [duration] [anim_path]
```

### 核心功能

| 函数 | 说明 |
|------|------|
| `clear_scene()` | 清空默认场景 |
| `import_fbx(fbx_path)` | 导入 FBX 模型，返回 Armature 对象 |
| `setup_camera(target_obj)` | 自动根据模型尺寸设置摄像机 |
| `setup_lighting()` | 设置三点光照（主光、补光、背光） |
| `setup_render(width, height, transparent)` | 配置 EEVEE 渲染参数 |
| `load_all_animations(anim_path)` | 加载 Mixamo 动画（支持单文件或目录） |
| `setup_animation(armature, anim_path, fps, duration_s)` | NLA 随机拼接动画填满时长 |
| `render_frame(output_path, frame)` | 渲染单帧 |
| `render_animation(output_dir, frame_start, frame_end)` | 渲染帧序列 |

### 动画拼接策略

- 单个动画：循环播放填满时长
- 多个动画：NLA 轨道随机拼接，打乱顺序防重复
- 支持 Mixamo 动画 FBX 文件

## 10. `composer.py` — 视频合成模块

### 功能

使用 FFmpeg 将幻灯片背景、数字人动画帧、音频合成为最终视频。

### 核心方法

| 方法 | 说明 |
|------|------|
| `concat_audio(audio_paths, output_path)` | 拼接多个音频文件 |
| `get_audio_duration(audio_path)` | 获取音频时长 |
| `compose(...)` | 完整合成：幻灯片 + 数字人 + 音频 + 字幕 |
| `compose_topic_video(...)` | 话题模式合成（含片头视频） |
| `compose_slides_only(...)` | 纯幻灯片模式（无数字人） |

### 合成流程

1. **生成幻灯片视频**：将每张幻灯片转换为视频片段，支持入场动画帧 + 静态停留
2. **页间转场**：支持 xfade 滤镜实现淡入淡出等转场效果
3. **最终合成**：
   - 幻灯片作为背景层
   - 数字人帧序列叠加到右下角（带白色半透明背景框）
   - 混入完整音频
   - 叠加 SRT 字幕（支持中文字体）

### 支持的字幕样式

```css
FontName=Microsoft YaHei, FontSize=14,
PrimaryColour=&H00FFFFFF, OutlineColour=&H00000000,
Outline=2, Shadow=1, MarginV=50
```

## 11. `main.py` — 主入口

### 功能

整个工具的入口脚本，协调各模块完成完整的视频生成流水线。

### 命令行参数

```
python main.py [选项]

选项：
  --text TEXT          讲解文本内容
  --text-file PATH     从文件读取讲解文本
  --script-json PATH   话题模式：口播文稿 JSON 路径
  --bg-dir PATH        话题模式：已有背景图目录
  --slides-dir PATH    已有幻灯片图片目录
  --model PATH         3D 模型路径（默认 asset/swat.fbx）
  --anim PATH          动画 FBX 文件或目录
  --output PATH        输出视频路径
  --voice VOICE        TTS 音色
  --rate RATE          TTS 语速（如 +10%）
  --no-avatar          跳过数字人渲染
  --config PATH        配置文件路径
```

### 流水线步骤

1. **获取输入文本**：命令行参数 / 文件 / 示例文本
2. **生成幻灯片**：自动 / 指定目录 / 跳过
3. **TTS 语音合成**：逐页合成 + 拼接
4. **渲染数字人**：Blender 渲染帧序列（可跳过）
5. **生成字幕**：SRT 格式
6. **视频合成**：FFmpeg 最终合成

## 12. `generate_video_from_report.py` — 桥接脚本

### 功能

连接 `ai-daily` 项目（金融日报生成器）与本项目，将生成的金融日报自动转为数字人口播视频。

### 命令行参数

```
python generate_video_from_report.py [选项]

选项：
  --topic [TOPIC]      指定主题生成视频（无参数自动选取热点话题）
  --topic-article PATH 整篇文稿文本或文件路径
  --not-convert        配合 topic-article：不经 LLM 改写
  --generate           一键模式：先生成日报再生成视频
  --report-path PATH   指定日报 txt 文件路径
  --date YYYY-MM-DD   指定日期
  --voice VOICE        TTS 音色
  --rate RATE          TTS 语速
  --output PATH        输出视频路径
  --no-avatar          跳过数字人渲染
  --genre GENRE        节目形态：daily_brief（默认）或 general
  --duration MIN       口播目标时长（分钟，默认 2）
  --intro NAME         片头文件名（asset/templates/started/）
  --max-videos N       背景最多视频段数（默认 0）
  --config PATH        配置文件路径
```

### 工作模式

1. **话题模式** (`--topic`)：搜索主题 → 生成文稿 → 生成视频
2. **文稿模式** (`--topic-article`)：文稿 → 口播结构 → 生成视频
3. **一键模式** (`--generate`)：生成日报 → 生成视频
4. **直接模式** (`--report-path` / `--date`)：使用已有日报 → 生成视频

节目形态由 `src/genre.py` 定义：`daily_brief` 保持「热点资讯」片头与时事结尾；`general` 片头使用脚本标题，配套通用口吻与结尾。`--genre` / `--duration` 仅作用于话题/文稿模式；`--intro` 在话题合成时覆盖配置中的片头。片头解析与开场白时长对齐见 `src/intro.py`。

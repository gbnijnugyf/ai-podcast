# 数字人口播工具 — 协作流程规范

## 核心规则

1. **未经允许不可编写代码。** 任何编码工作必须在用户明确允许后才能开始。
2. **先规划后执行。** 实现需求前必须先规划步骤，经用户确认后才可推进。
3. **逐步验收。** 每一步完成后需要用户明确确认验收通过，才可进行下一步。
4. **环境搭建由用户操作。** 涉及 Python 依赖安装、软件安装、环境配置等操作，由 Agent 提供具体步骤，用户自行执行。
5. **编码外操作由用户执行。** 下载文件、下载应用、访问网站等操作，由 Agent 提供步骤，用户自行执行。
6. **Python 环境约束。** 该项目所有 Python 相关操作必须在 `ai-podcast` conda 环境中执行（Python 3.11）。命令示例：`conda activate ai-podcast`。

## 工作流程

```
用户提出需求
    │
    ▼
Agent 规划步骤（更新 PLAN.md）
    │
    ▼
用户确认步骤 ──否──→ Agent 修改步骤
    │
    是
    ▼
┌─────────────────────────────────┐
│ 逐步执行（循环）                 │
│                                 │
│  判断步骤类型：                  │
│  ├─ 环境搭建 → 告知用户操作步骤  │
│  ├─ 下载/外部操作 → 告知用户步骤 │
│  └─ 编码 → 等用户允许后编写代码  │
│                                 │
│  完成后 → 用户验收               │
│  ├─ 通过 → 进入下一步           │
│  └─ 不通过 → 修改后重新验收     │
└─────────────────────────────────┘
    │
    ▼
全部步骤完成
```

## 方案文档

项目根目录的 `PLAN.md` 是唯一的方案文档，所有技术决策和步骤规划都记录在其中。修改前需与用户对齐。
